# AI Usage Documentation

## AI Tools Used

ChatGPT was used as an AI assistance tool during the development of FocusBoard.

## How AI Was Used

1. **Project Setup:** Assistance with setting up React JS and Vite.
2. **Component Development:** Guidance on creating reusable React components.
3. **UI Development:** Help with dashboard layout and responsive CSS.
4. **Functionality:** Guidance on implementing task management, search, filters, and LocalStorage.
5. **Debugging:** Help identifying and resolving development issues.
6. **Documentation:** Assistance preparing the README and project documentation.

## Developer Contribution

The developer created and organized the project, implemented the provided code, ran the application, and tested its main features.

## Testing

The following features were tested:

- Add, edit, and delete tasks
- Search and filtering
- Task status updates
- Priority filtering
- LocalStorage persistence
- Focus Notes carousel
- Responsive layouts
- Keyboard navigation

## Declaration

AI tools were used for learning and development assistance. The final project was run and tested by the developer.
