# FocusBoard – Task Management Dashboard

FocusBoard is a responsive task management dashboard built using React JS and Vite.

## Features

- Add, edit, and delete tasks
- Track To do, In Progress, and Completed tasks
- Set Low, Medium, and High priorities
- Search tasks by title
- Filter tasks by status and priority
- Dynamic dashboard statistics
- Focus Notes carousel
- LocalStorage persistence
- Responsive mobile, tablet, and desktop layouts

## Technologies

- React JS
- Vite
- JavaScript
- CSS
- Lucide React
- LocalStorage

## Installation

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Data Storage

Tasks are stored in the browser using LocalStorage. No backend or database is required.
